# Release steps (not part of the published repository; delete before pushing if you like)

1. Confirm the author has checked her employer's publication/IP policy and is happy to release.
2. Replace the placeholders in `CITATION.cff` (GitHub username and repository name).
3. Create a public GitHub repository and push this folder (the author does the commit and push).
4. On zenodo.org, sign in with GitHub, enable the repository, then create a GitHub release `v1.0.0`. Zenodo mints the DOI.
5. Add the DOI to `CITATION.cff` (uncomment the `doi:` line) and to the README, and to each paper's reproducibility statement.
6. Post preprints: SSRN first, then arXiv (may need an endorsement; not guaranteed). Record the dates and links.
7. Update the innovation form: repository link, DOI, preprint links, dates, and screenshots. Add stars, forks or citations only when they exist.
